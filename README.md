# ORI Verification｜台灣選舉民調觀察

這是一個靜態互動研究網站，使用已蒐集的選前民調與實際開票資料，比較來源系列在不同選舉中的誤差。網頁可依選區、年份及來源篩選，檢視逐筆資料與來源、比較兩個系列的共同場次，並顯示候選人支持率與開票的圖表。

## 研究邊界

- 探索性研究初版，資料截至 2026-11-18。主分析有 237 份民調、50 場選舉；另收錄 79 場選舉的開票資料。
- 目前尚非 1950 年以來所有選舉及所有民調的完整普查。1996 年選前民調、2009 年以前地方選舉及部分原始報告仍未蒐齊；多數地方開票與部分委託、執行身分尚待逐筆核對。
- 民調支持率及實際得票先按同一候選人組合比例化，假設未表態者依已表態者的比例分配。這是比較假設，不等於調查機構自己的選票預估。
- 所有機構級距均依有限樣本及自訂門檻試算，不是完整歷史排名；「完全不準確」是指定級距名稱，並不表示每份調查都錯。政黨配對只能描述樣本，不能推論因果或指控造假。

## 檔案

- `index.html`、`styles.css`、`core.js`、`app.js`：靜態網站，不需要後端或套件。
- `data.js`：網站使用的民調、選舉及政黨配對資料；逐筆資料包含網址與品質備註。
- `report.pdf`、`data.xlsx`：研究報告與可篩選試算表。
- `tests/poll-logic.test.cjs`：資料換算、年度等權與同場配對的測試。

本機預覽可在此目錄執行 `python3 -m http.server 4173`，再開啟 `http://localhost:4173/`。使用 Node.js 可執行 `node --test tests/poll-logic.test.cjs`。本網站適合從 GitHub Pages 的預設分支根目錄發佈。
