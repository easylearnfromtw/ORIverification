# ORI Verification｜台灣選舉民調觀察

這是一個靜態互動研究網站，使用已蒐集的選前民調與實際開票資料，比較來源系列在不同選舉中的誤差。**收錄不限定封關、最後一次或特定選前天數**；同一機構同場不同波次的可查證調查應逐筆保留。**首頁直接完整顯示所有已收錄來源系列**，達評級門檻的來源依年度等權平均絕對差排名，未達門檻的來源仍列示分數但不給正式名次。網頁可依選區、年份及來源篩選，檢視逐筆資料與來源、比較兩個系列的共同場次，並顯示候選人支持率與開票的圖表。

## 研究邊界

- 探索性研究初版，資料截至 2026-11-18。主分析有 237 份民調、50 場選舉；另收錄 79 場選舉的開票資料。
- 目前尚非 1950 年以來所有選舉及所有民調的完整普查。1996 年選前民調、2009 年以前地方選舉及部分原始報告仍未蒐齊；多數地方開票與部分委託、執行身分尚待逐筆核對。
- 民調支持率及實際得票先按同一候選人組合比例化，假設未表態者依已表態者的比例分配。這是比較假設，不等於調查機構自己的選票預估。
- 所有機構級距均依有限樣本及自訂門檻試算，不是完整歷史排名；「完全不準確」是指定級距名稱，並不表示每份調查都錯。政黨配對只能描述樣本，不能推論因果或指控造假。

## 檔案

- `index.html`、`styles.css`、`core.js`、`app.js`：靜態網站，不需要後端或套件。
- `data.js`：網站使用的民調、選舉及政黨配對資料；逐筆資料包含網址與品質備註。
- `report.pdf`、`data.xlsx`：研究報告與可篩選試算表。
- `tests/poll-logic.test.cjs`：資料換算、年度等權與同場配對的測試。

本機預覽可在此目錄執行 `python3 -m http.server 4173`，再開啟 `http://localhost:4173/`。使用 Node.js 可執行 `node --test tests/poll-logic.test.cjs`。本網站適合從 GitHub Pages 的預設分支根目錄發佈。

## 全波次收錄規則

- 不以封關民調、最後一份、投票前 11–30 天作為收錄條件。每一波有公開數字與可追溯來源的調查，原則上獨立建檔，保留調查日期、發布日期、執行機構、委託者、題目、樣本數與方法。
- 選舉投票意向若可與正式開票比對，納入誤差計算；政策民調、施政滿意度及沒有對應開票結果的調查可收錄但不進選舉準確度榜。
- 同一機構同場不同波次不得當成多場獨立選舉；來源對照的同場誤差改以各波平均，而非選取最後一次。跨年份的主排名仍使用年份等權；日後應提供距投票日分層分析，避免遠期民調因民意變動而被誤判為品質差。
- 此變更是資料收錄及網站方法規則；目前既有資料仍為先前蒐集的樣本，尚未補完所有歷史波次。

## 罷免民調納入總排名（2026-11-18）

- 鏡新聞 2025/07/14 臺中六選區罷免態度民調已與中選會 7/26、8/23 正式開票配對，新增六筆至 data.js 的 polls，納入同一準確度總榜。可於「選舉類型 → 罷免投票」篩選。
- 比對全體受訪者同意／不同意比例化後的同意票率與正式有效票率；各筆含同意／不同意票數、選舉人總數、調查與開票來源。未使用「一定會投票」子樣本作為主分數，避免混淆分母。
- 同一調查不同選區是六筆獨立選區觀察，但仍共享同一波發布、調查方法及政治環境；與一般選舉合併的總榜只是探索性混合指標，不可解讀為因果或機構能力的無偏估計。
- 中選會 8/23 結果：https://web.cec.gov.tw/central/article/61261 ；7/26 結果：https://web.cec.gov.tw/api/file/b35ac130-d35d-4a9e-a145-cee7b7c4b8d2.pdf
